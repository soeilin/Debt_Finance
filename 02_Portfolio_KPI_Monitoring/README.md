# Portfolio KPI Monitoring (MoM / Risk Trends)

## Objective
To build a lightweight dashboard showing month-on-month changes in key retail-credit portfolio metrics.

## Metrics Tracked
• Bad rate (30+ DPD)  
• Early-arrears formation  
• Approval/decline rates  
• Utilisation rate  
• Vintage performance (lite version)  

## Methods
• Synthetic monthly data (12 periods)  
• KPI calculations in Python / Excel  
• Trend plots and variance commentary  

## Outputs
• MoM risk movement  
• Highlight of deteriorating / improving segments  
• Early warning signals  
• Business-focused insights  

## Skills Demonstrated
Portfolio thinking, KPI variance analysis, storytelling with risk data.
