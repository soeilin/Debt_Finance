# K-Means Segmentation — Behavioural & Risk Clustering

## Objective
To segment customers into groups with similar behavioural or credit-risk characteristics, supporting differentiated credit strategies.

## Features Used
• Utilisation  
• Payment ratio  
• Delinquency flags  
• Balance behaviour  

## Methods
• Standardisation  
• K-Means clustering  
• Cluster profiling  
• Action mapping (e.g., reduce limit, maintain, watch-list)  

## Outputs
• Cluster definitions  
• Risk gradient across clusters  
• Strategy recommendations  

## Skills Demonstrated
Unsupservised learning, business translation of segmentation, Python workflow.
