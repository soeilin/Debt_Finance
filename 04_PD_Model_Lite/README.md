# PD Model Lite — Logistic Regression (Baseline)

## Objective
To build a simple, interpretable baseline model that estimates probability of default using logistic regression.

This is *not* a production-grade scorecard.  
It focuses on intuition and business interpretation.

## Features
• Age  
• Income  
• Utilisation  
• Delinquency history  
• Recent credit enquiries  

## Methods
1. Train/test split  
2. Logistic regression  
3. Coefficient interpretation  
4. ROC/AUC & ranking  
5. PD grouping (high/medium/low)  

## Outputs
• Key PD drivers  
• PD lift between groups  
• Cut-off simulation (simple scenario)  
• Risk-based business commentary  

## Skills Demonstrated
Understanding of PD mechanics, basic modelling, uplift evaluation, and risk insight generation.
