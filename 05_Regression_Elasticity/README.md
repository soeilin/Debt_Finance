# Regression Analysis (Elasticity / Drivers)

## Objective
To quantify the impact of key variables on a commercial or portfolio outcome (e.g., spend, utilisation, revenue).

## Methods
• Regression modelling (OLS)  
• Multicollinearity checks (light)  
• Residual interpretation  
• Practical elasticity commentary  

## Outputs
• Key drivers ranked by influence  
• Partial effects  
• Business translation (e.g., “+10% utilisation → +x% revenue”)  

## Skills Demonstrated
Statistical reasoning, business translation, and cross-domain analytical thinking.
