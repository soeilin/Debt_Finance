# Credit Strategy Lite — Rule-Based Decisioning Prototype

## Objective
To demonstrate understanding of automated lending logic by building a simplified, rule-based decision-strategy prototype.  
This mirrors how credit engines process applications using cut-offs, high-risk flags, and policy conditions.

## Key Components
• Basic affordability checks (DTI, income thresholds)  
• Bureau-style risk flags (new-to-credit, recent arrears, high utilisation)  
• Policy triggers (max LVR, recent hardship, risky segments)  
• Final approval / decline / refer-for-review logic  

## Methods
A synthetic dataset is processed through three layers:
1. Applicant rules  
2. Behavioural rules  
3. Final decision tree  

No machine learning is used — this is purely deterministic logic.

## Outputs
• Approval/decline distribution  
• Drivers behind declines  
• Segment-level cut-off impact  
• Policy-risk trade-off commentary  

## Skills Demonstrated
Business thinking, credit fundamentals, decision flow design, and clear communication of credit-policy outcomes.
